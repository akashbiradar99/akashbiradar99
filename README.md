### 🚀 About Me

I'm a **Backend Engineer with 4+ years of experience** building and scaling **multi-tenant SaaS** services at **HubEngage** — an employee engagement and content management platform.

- 🧱 I own features **end-to-end**: REST API design → validation → service logic → custom data access → schema migrations → production.
- 🤖 I build **AI-powered backend services** in Python (OpenAI, LangChain) and treat LLMs as *unreliable dependencies* — schema validation, retry loops, defensive JSON parsing and caching.
- ⚡ I care about **query performance and clean architecture**: composite indexes, N+1 elimination, lightweight query layers, idempotent bulk operations.
- 🌱 Always learning — this GitHub is my **public playground** for Go, modern Java and DSA.
